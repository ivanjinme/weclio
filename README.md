# Weclio

[中文](./README.zh-CN.md)

An agent harness built on [Pi](https://github.com/badlogic/pi-mono), with a web UI and desktop app.

## Requirements

Node.js 22.19.0 or newer. Both Web and Desktop run the Agent Service on your installed Node; Desktop does not bundle a runtime.

## Development

```bash
npm install
npm run dev           # Desktop (default)
npm run dev:desktop   # Desktop
npm run dev:web       # Web
```
