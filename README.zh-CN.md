# Weclio

[English](./README.md)

基于 [Pi 编程智能体](https://github.com/badlogic/pi-mono)构建的 harness，提供 Web 和 Desktop 双入口。

## 环境要求

Node.js 22.19.0 或更新版本。Web 与 Desktop 都用你自己安装的 Node 运行 Agent Service，Desktop 不自带运行时。

## 开发

```bash
npm install
npm run dev           # 桌面（默认）
npm run dev:desktop   # 桌面
npm run dev:web       # Web
```
